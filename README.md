# Smart Calculator

## Project Description
Smart Calculator is a Python-based calculator that performs different mathematical operations using functions and loops.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Exit option

## Technologies Used
- Python 3
- Visual Studio Code

## Concepts Used
- Functions
- While Loop
- If-Else Statements
- Variables
- Input and Output

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

```bash
python calculator.py
```
